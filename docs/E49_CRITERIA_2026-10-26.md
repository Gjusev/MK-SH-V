# E49 criteria (FROZEN 2026-10-26, before any E49 row is generated or measured)

## Question

The released checkpoint (E47 seed 43, E48 policy) detects end-of-task
screens but grounds the goal only partly: on the E43 goal-swap set (M3) it
rejects an unrelated goal 0.785 / 0.775 of the time (s42 / s43) against the
0.80 bar frozen since E44, with own-goal accuracy 0.855 / 0.850.

A per-episode read of the E47 M3 files (done before this document, on the
already-reported M3 outputs only) shows:

- swap failures are **not** concentrated on similar goals: with token
  Jaccard < 0.1 between own and swapped goal (359 of 400 swaps) accuracy is
  still 0.802 / 0.794;
- only 260 / 256 of 400 episodes are right both ways (own true, swap false);
  82 / 84 get "true" both ways, i.e. finished-screen detection only;
- some swapped goals are generic ("turn on/off notifications for any app on
  the phone and open the app", "install a shopping app and open the app") and
  are arguably satisfied by many final screens. M3 therefore carries some
  label noise. The rule is **not** changed here; this is stated so it is not
  discovered after the result.

The training goal questions come from only 1,096 E41 train episodes (one
own/other pair and one four-way goal-match each), seen across four fine-tunes.
**Hypothesis: the model ties screens it has seen to their goals instead of
reading the goal; more distinct episodes, with nothing else changed, improve
goal grounding on unseen episodes.**

## Data (generated by `scripts/gen_e49.py` after this commit)

- Source: GUI-Odyssey task_split **train**, COMPLETE episodes, the E41
  candidate procedure (stream, keep episodes whose last action is COMPLETE,
  sort by the same sha256 key), with the scan widened from 3,600 to up to
  9,000 candidates. Excluded and asserted: every E41 episode (train and dev),
  every E43 episode, every E38c episode, every task_split test episode.
- Only the final screenshot of each episode is fetched (original bytes).
  Episodes are taken in the sorted order until 2,400 have a fetchable final
  screenshot: the **first 400 form M3F**, the **next 2,000 are training
  episodes**.
- **M3F (fresh goal-swap set, never trained on, read once per seed):** for
  each of the 400 episodes, the final screenshot with its own goal (gold
  true) and with the next different goal in the M3F order (gold false), EN,
  exactly the E43 swap rule. 800 rows.
- **Bind pool v4:** every E47 bind row unchanged (rows sha `d3236aed…`), plus
  for each of the 2,000 training episodes, built as the E45 goal kinds: one
  `goal` pair (own goal true; another goal false, drawn uniformly from the
  goals of all 3,096 training episodes, own excluded) and one `goal_match`
  four-way question (own + three uniform others, own at a deterministic
  random position), language cycling EN/ES/DE, `img_src = "bind"` (images
  shipped inside the bind dataset). All new rows are train split; bind dev is
  E47's unchanged, so the selection key is computed on the same rows.

## Arm (one arm, two seeds)

- Init: the E47 checkpoints (s42 `8b166fb9…`, s43 `afcbeaa4…`, the released
  seed), read from kernel `gjusev/mkshv-e47-train`, sha-verified.
- Everything else exactly E47: U1024 input rule, recipe, slots, optimiser,
  800 steps, dev cadence 200, selection key, pool weights (num_syn 0.20,
  num_cord 0.10, cmp_text 0.05, digits 0.20, range 0.05, goal 0.20,
  goal_match 0.20), allocator setting. The only change is the larger goal
  and goal_match pools.

## Measurements

As E47 (M1 probe, M2 E38a field_threshold test, M3 E43 swap + own, M4 E38c
CORD, N1 synthetic test non-FR, N2 E38c GUI, N3 testC / task), with the U1024
rule everywhere, plus **M3F** (`scripts/e43_infer.py --upscale 1024`).
Reported without a gate: per-episode both-right counts on M3 and M3F, and
M3F swap accuracy excluding swapped goals that contain the word "any".

## Gates (both seeds each)

- **G2 goals (the question):** M3 swap ≥ 0.80 and M3 own ≥ 0.80, **and**
  M3F swap ≥ 0.80 and M3F own ≥ 0.80. M3F is required because M3 has been
  read as a gate four times.
- **G1 numbers kept:** M2 ≥ 0.70.
- **G3 no regression against E47, exact counts per seed:** N1 drop ≤ 2 pp,
  N2 GUI task_done drop ≤ 3 pp, N3 testC and task drop ≤ 3 pp each, M4 CORD
  drop ≤ 3 pp.

Outcome: if G1, G2 and G3 hold, the public goal claim may move beyond
"end-of-task screen detection", but only after a recalibration of the E49
checkpoints under the E42 protocol, frozen as its own experiment (as E48 did
for E47). Otherwise everything is reported as measured and the release stays
E47.

## Budget and guards

One GPU kernel, both seeds in parallel (T4×2), one shot after a 20-step
smoke. E47 took 10,771 s wall; E49 adds only rows and images to the bind
pool, estimate ≈ 11,000 s. Quota before E49: 46,157 s of 108,000 s (refresh
2026-10-31). The kernel aborts before any GPU work if the bind rows sha, the
init sha or any bind image is missing. The user gave the GO for data, Kaggle
and pushes on 2026-10-26 ("dale con todo").
