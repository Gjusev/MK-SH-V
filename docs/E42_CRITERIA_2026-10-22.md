# E42 criteria (FROZEN 2026-10-22, before any measurement)

## Question

E40 calibrated the E39 checkpoints and produced **zero claimable abstention
sets**: τ chosen on cal_policy by POINT risk ≤ 5 % landed the operating point
on the budget edge, so the held-out Clopper-Pearson upper bound exceeded 5 %
on test for 2 of 3 seeds (by 0.2–0.7 pp; with τ = 0.60 all three would have
passed — post hoc, never claimed). E41 then changed the models: with real
training data, real accuracy rose to 0.765/0.742 and real ECE fell to 0.10.

**E42 measures calibration and abstention of the two E41 checkpoints with the
one rule E40's evidence says was wrong, fixed here in writing before any E41
calibration output exists: τ is chosen by the CP95 upper bound, not by point
risk.** Everything else is E40's frozen protocol unchanged.

## Protocol (inherited verbatim from E40 `7509f43`+`3b0fa8b` unless stated)

- Sets and order: T fitted on cal_temperature (3,150; NLL grid 0.50–3.00
  step 0.01 + ternary refinement); τ on cal_policy (3,150); held-out tables
  on test non-FR (4,200), test FR (1,400), CORD (576), GUI (2,010), testC
  (48), task (300), with per-family sub-tables for test non-FR/FR.
- Clopper-Pearson exact two-sided 95 % (MK-SH-1 E36 convention); risk budget
  5 % judged on the UPPER end.
- **Only change — τ rule (frozen here, before any E41 calibration data is
  produced or read):** τ = smallest value on the frozen grid
  {0.30, 0.35, …, 0.95} whose cal_policy CP95 UPPER bound of selective risk
  ≤ 0.05. If no grid value qualifies, τ = 0.95 and `met_target: false` is
  reported. MK-SH-1's `policy.pick_threshold` (point risk) is computed and
  reported as a cross-check only, never used for the operating point.
- Reported, no gate: risk-coverage curves per set and family; ECE15 and NLL
  raw vs T; doc/screen T ablation; raw accuracies; mokka `fit_temperature`
  cross-check.

## Claim rule

A held-out set is **claimable** iff its CP95 upper bound at the chosen τ is
≤ 0.05 for BOTH seeds (E41 has two; the all-seeds rule is unchanged in kind).
Claims never use cal splits. Calibration/abstention on real data is reported
as measured; no post-hoc re-tuning on held-out sets.
