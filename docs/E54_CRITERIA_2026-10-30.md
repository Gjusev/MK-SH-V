# E54 — train-time-only auxiliary digit heads (criteria frozen 2026-10-30)

Frozen BEFORE any E54 number is computed. Pre-freeze evidence: the E52 format
coverage lifted the receipt family to 0.54-0.64 but real CORD moved little in
the training-kernel eval (-0.2 to -0.5 pp; +4.2 pp under the calib protocol,
discrepancy recorded in E53) — the remaining receipts gap is digit PERCEPTION.
E45 localized perception as the bottleneck; this experiment forces the encoder
to encode every printed digit via auxiliary supervision.

## Design (frozen)

- Model: `NeoMMEAuxScorer` (src/mksh_v/arch_a1v_aux.py, a SUBCLASS — the frozen
  A1 file is untouched). Nine added tokens ([DIGIT_1..8] [LEN]) appended after
  each case tail; a shared-hidden 10-way digit head per position and a 9-way
  length head. Labels from each bind row's `total` via `sig_digits` (idr
  convention for img_src e41 and fmt idr). Aux weight **0.5** on bind slots
  only; the heads are discarded for deployment (`strip_aux`).
- Init from the pinned E52 checkpoints (s42 3d2ffdbc…, s43 dfc6d60e…), pool v4
  (dataset mkshv-e52-bind v2, rows sha 351b5505…), weights, U1024, 800 steps,
  dev cadence and the frozen selection key identical to E52. Budget:
  train deadline 3.9 h, wall 5.2 h (the E52 lesson — 3.2 h cut the eval tail).
- Aux labels exist on num_syn, num_cord, digits, range and receipt rows (any
  bind row carrying `total`).

## Gates (fail any → negative; no post-hoc changes)

- **A1 (mechanism)**: aux digit accuracy at positions 1-4 on bind dev ≥ 0.90
  for both seeds at the best step (reported per position 1-8 descriptively).
  If the heads themselves fail to learn, the run reads negative regardless of
  the choice metrics.
- **A2 (numbers)**: fresh EUR (E48 set, read via the same local protocol as
  E52's finishers) ≥ 0.80 for both seeds (E48-C1 level; E52 measured 0.792 and
  the recalib 0.8213).
- **A3 (no regression, exact per-case counts vs the E52 checkpoints of the
  same seed)**: synthetic test non-FR ≤ 2.0 pp; real GUI ≤ 3.0 pp; real CORD
  as an exact-count guard (no CI, no headline); task and testC ≤ 3.0 pp;
  receipt-fresh (the e52 fresh set, 2,400) ≤ 3.0 pp; M3 swap and own ≤ 3.0 pp.
- Deployment note: a positive run still requires the recalibration experiment
  (E42/E48 protocol) before any release; the aux checkpoint exports via
  `strip_aux` and the exported artifact must re-pass A3's Cord/GUI guards
  before being considered.

## Cost

One two-seed T4x2 kernel, ~3.5-4 h wall (~14k s quota, post-refresh).
